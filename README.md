
# ⛓️ Blockchain Assignment Tracker

A web-based practice platform designed to help students revise blockchain concepts through weekly multiple-choice questions, instant feedback, and explanations.

## 🚀 Overview

Blockchain Assignment Tracker organizes blockchain course practice questions into 12 weekly modules. Students can select a week, attempt questions, check their answers, and track their scores.

## ✨ Features

- 📚 12 weekly blockchain learning modules
- ❓ Multiple-choice practice questions
- ✅ Instant answer validation
- 📊 Live score and attempted-question counter
- 💡 Explanations for answers
- 📱 Responsive layout for mobile devices
- 🎨 Simple and user-friendly interface

## 📖 Course Modules

| Week | Topics |
|---|---|
| 1 | Blockchain Foundations |
| 2 | RSA & Merkle Trees |
| 3 | Bitcoin Mechanics |

| 7 | Fabric & PBFT |

| 11 | Aries & Security |
| 12 | Real-world Use Cases |

## ⚙️ How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/ArvindBuilds/Blockchain-Assignment-Tracker.git
```

2. Open the project folder:

```bash
cd Blockchain-Assignment-Tracker
```

3. Start a local development server:

```bash
python -m http.server 8000
```

4. Open your browser and visit:

```text
http://localhost:8000
```
